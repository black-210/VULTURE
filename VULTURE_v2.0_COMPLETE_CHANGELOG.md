## 📦 Installation & Setup

### Requirements
- Python 3.10+
- CUDA 11.8+ (for GPU acceleration)
- 8GB+ RAM
- Linux/macOS/Windows

### Quick Install

```bash
# Clone repository
git clone https://github.com/black-210/VULTURE.git
cd VULTURE

# Install dependencies
pip install -r requirements.txt
```
