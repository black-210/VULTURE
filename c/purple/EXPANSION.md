# VULTURE C Purple Team Expansion

This directory adds a controlled local analytics layer for joint adversary-emulation review and defensive validation. The modules deliberately operate on supplied numeric files only. They provide baselines, residual comparison, control assertions, and provenance notes; they do not implement exploitation, persistence, evasion, credential access, network scanning, RF transmission, or device discovery.

Build with `make -C c -f Makefile.purple purple`.
