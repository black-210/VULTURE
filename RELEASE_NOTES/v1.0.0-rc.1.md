# RELEASE NOTES — v1.0.0-rc.1

This is a release-candidate draft for v1.0.0. The candidate includes the following major additions and improvements (Batch A + Batch B):

- DSP: PSD implementations (Welch & Periodogram), spectrogram generation, peak detection utilities, and GPU FFT helpers (CuPy fallback).
- SDR: RTL-SDR adapter wrapper for pyrtlsdr with mock-friendly tests and example recording utilities.
- ML: TorchTrainer minimal loop with checkpointing and ONNX export helper.
- Model Hub: Local model repository with add/list/verify and ONNX loader helper.
- Plugin System: Marketplace MVP and process-based sandbox runner (with Docker shim fallback).
- GUI: Wiring helpers to connect backends to PyQt GUI panels for demos.
- Benchmarks: PSD/FFT benchmarking utility and documentation for measuring CPU/GPU throughput.

Known limitations & next steps (to reach production-grade v1.0.0):
- Harden plugin sandbox (container orchestration, seccomp/apparmor, network restrictions).
- Integration tests with real hardware (RTL-SDR, UHD/USRP, PlutoSDR).
- GPU benchmark CI and performance tuning (CuPy/Numba/FFT optimizations).
- Full PyTorch training pipelines, dataset recipes, and example datasets.
